# CareNest App 👵👴  
A mobile healthcare application designed to support **elderly care and assistance**, built using **Kotlin** in **Android Studio**. CareNest combines usability with essential features like **medication reminders**, **emergency alerts**, a **memory game**, and **caregiver communication**, making it a digital companion for seniors.

## 🧠 Key Features  
- **Medication Reminders**: Schedule and receive alerts for medications.  
- **Emergency Alerts**: Instantly notify caregivers in case of emergencies.  
- **Memory Game**: Engage seniors with cognitive exercises to support mental health.  
- **Caregiver Communication**: Direct and simple messaging interface for caregivers and patients.  
- **Accessibility-Focused UI**: Large fonts, high contrast, and intuitive design tailored for elderly users.  
- **Secure Health Logs**: Stores health-related data locally using **SQLite**.

## 🛠️ Tech Stack  
- **Language**: Kotlin  
- **IDE**: Android Studio  
- **Database**: SQLite
